# Money Transfer App Frontend

## Overview

This project is a React + TypeScript application bootstrapped with [Vite](https://vitejs.dev). It serves as the frontend part of the money transfer application and provides the user interface.

## Required Versions

- **Node.js**: 24
- **React**: 18.3.1
- **TypeScript**: 5.5.3

## API Connection Settings

The frontend accesses the backend API through the Vite dev server proxy using relative paths (`/api/...`).
