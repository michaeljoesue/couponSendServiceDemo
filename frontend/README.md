# 送金アプリ フロントエンド

## 概要

このプロジェクトは、[Vite](https://vitejs.dev)を使用してブートストラップされた React + TypeScript アプリケーションです。送金アプリのフロントエンド部分を担当し、ユーザーインターフェースを提供します。

## 必要なバージョン

- **Node.js**: 24
- **React**: 18.3.1
- **TypeScript**: 5.5.3

## API接続設定

フロントエンドは Vite dev server の proxy 経由で相対パス (`/api/...`) でバックエンド API にアクセスします。
