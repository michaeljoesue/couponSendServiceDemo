# 送金アプリ

## 概要

送金アプリは、ユーザーアカウント間でポイントを送金することができるように設計されたウェブベースのアプリケーションです。このアプリは、Reactを使用したフロントエンドと、Ruby on Railsを使用したバックエンドで構成されており、データストレージにはSQLiteデータベースを利用しています。ユーザーは、ポイントを他のユーザーへ送金することが可能です。

## 必要なバージョン

- **Ruby**: 3.2.2
- **Rails**: 7.1.2
- **Node.js**: 24
- **React**: 19

## 起動方法

このアプリケーションをDocker Composeを使用して起動する手順は以下の通りです。

### 前提条件

以下のソフトウェアがシステムにインストールされていることを確認してください。

- Docker
- Docker Compose

### アプリケーションの起動

1. **リポジトリをクローンする**:

   ```bash
   git clone https://github.com/<your-username>/take-home-<id>.git
   cd take-home-<id>
   ```

2. **コンテナをビルドして起動する**:

   以下のコマンドを実行して、フロントエンドとバックエンドサービスのDockerコンテナをビルドし、起動します。

   ```bash
   docker compose up --build
   ```

   このコマンドは、`docker-compose.yml`ファイルに定義されたサービスをビルドし、起動します。

3. **アプリケーションにアクセスする**:

   コンテナが起動したら、フロントエンドは port 3000、バックエンド API は port 8080 (`/api/accounts`, `/api/balances`) で稼働します。

アプリケーションを立ち上げると以下の状態となります:

- ホットリロード機能が有効になります。コードを変更すると、自動的に再ビルド・再起動されます。
- データベースのセットアップは、アプリケーションの起動時に自動的に行われます。

### アプリケーションの停止

実行中のコンテナを停止するには、以下のコマンドを使用します。

```bash
docker compose down
```
